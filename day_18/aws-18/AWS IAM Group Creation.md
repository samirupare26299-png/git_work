# AWS IAM Group Creation

## Task
Create an IAM group named `iamgroup_anita`.

## Requirements

IAM Group Name:


iamgroup_anita


## Steps (GUI)

1. Login to AWS Console.

2. Open:


IAM (Identity and Access Management)


3. Go to:


IAM → User groups


4. Click:


Create group


5. Enter group name:


iamgroup_anita


6. Click:


Create group


7. Verify:


IAM → User groups → iamgroup_anita


## Result

IAM group `iamgroup_anita` created successfully.
