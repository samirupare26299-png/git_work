# AWS IAM User Creation

## Task
Create an IAM user named `iamuser_kirsty`.

## Requirements
- IAM User Name:

iamuser_kirsty


## Steps (GUI)

1. Login to AWS Console.

2. Open:

IAM (Identity and Access Management)


3. Go to:

IAM → Users


4. Click:

Create user


5. Enter user name:

iamuser_kirsty


6. Continue with default settings.

7. Click:

Create user
